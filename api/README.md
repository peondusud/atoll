# API contracts

Language-neutral contracts shared by the Go and Rust versions of Atoll (`specs.md` §29.3). Any change here is a contract change: ask first (`CLAUDE.md`).

| Path | Content |
|---|---|
| `openapi.yaml` | The local API (`specs.md` §25.1): HTTP/1.1 and JSON over a Unix socket (named pipe on Windows), and over TCP with a token. Each answer has the schema of the command it mirrors. Its one write, `POST /v1/guards/{id}`, an answer to a guard, takes the body `GuardAnswerRequest`, which it defines, and answers as `atoll guard confirm` or `reject` does. |
| `schemas/` | JSON schemas of the `--json` outputs of the CLI (`specs.md` §25). |
| `metrics.json` | The Prometheus metrics of `/metrics` (`specs.md` §23.1): each metric's name, type, labels and help, in the order they are written, and its name and unit over OTLP. The binary embeds it (`api.go`), `conformance/vectors/metrics.json` pins the text, and `conformance/vectors/otel_names.json` the translation that gives each Prometheus name back from its OpenTelemetry name. |

Schemas use JSON Schema draft 2020-12, and refuse unknown fields. Defined so far: `schemas/names-check.schema.json`, for `atoll names check` (`specs.md` §15.9), `schemas/rules-check.schema.json` and `schemas/rules-explain.schema.json`, for `atoll rules check` and `atoll rules explain` (`specs.md` §11.3, §25), `schemas/disk-list.schema.json`, for `atoll disk list` (`specs.md` §10, §25), `schemas/init.schema.json` and `schemas/scan.schema.json`, for `atoll init` and `atoll scan` (`specs.md` §15.10, §25), `schemas/status.schema.json`, for `atoll status` (`specs.md` §15.11), `schemas/replicate.schema.json`, for `atoll replicate` (`specs.md` §14.3), `schemas/prune.schema.json`, `schemas/trash-list.schema.json`, `schemas/trash-restore.schema.json` and `schemas/trash-purge.schema.json`, for `atoll prune` and `atoll trash` (`specs.md` §17.3, §17.4), `schemas/daemon.schema.json`, `schemas/guard-list.schema.json` and `schemas/guard-answer.schema.json`, for `atoll daemon --until-idle` and `atoll guard` (`specs.md` §15.6, §15.12), `schemas/mergerfs-config.schema.json`, for `atoll mergerfs-config` (`specs.md` §21.1), and `schemas/polkit-rule.schema.json`, for `atoll polkit-rule` (`specs.md` §15.13, §25). `openapi.yaml` describes the local API, and a test checks that it lists exactly the paths the daemon answers.
